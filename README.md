# KeywordMap

> 대한민국 실시간 로컬 트렌드 맵 — 줌인할수록 선명해지는 동네 키워드

## 1. 서비스 개요

- **한줄 정의:** 대한민국 지역별 실시간 트렌딩 키워드를 지도의 줌인/아웃과 카테고리 필터로 직관적으로 탐색하는 데이터 시각화 웹서비스
- **핵심 가치:** 기존 지도는 '핀(Pin)' 중심이라 클릭 피로도가 높다. 본 서비스는 **지리적 위치 위에 '텍스트 키워드'가 직접 노출**되어 1초 만에 지역 트렌드를 파악할 수 있는 직관성을 제공한다.

## 2. 핵심 기능 (Core Features)

### 2.1 실시간 키워드 매핑
- SNS(X, 인스타그램), 포털, 커뮤니티 데이터를 수집
- 행정구역별 실시간 핫 키워드를 추출하여 지도 위에 시각화

### 2.2 다이내믹 줌인/아웃 (Dynamic Zoom In/Out)
- **줌아웃 (전국 단위):** 광역 지자체 중심의 거대 트렌드 노출 — 예: `#부산` `#해운대` `#국밥`
- **줌인 (동네 단위):** 읍/면/동 및 골목 단위로 세분화된 촘촘한 키워드 노출 — 예: `#전포카페거리` `#두바이초콜릿` `#에스프레소바`

### 2.3 카테고리 필터링 (Category Filter)
- 맛집, 카페, 뷰스팟, 문화/행사 등 사용자가 원하는 카테고리를 선택
- 선택한 카테고리의 트렌드 키워드만 지도 위에 필터링 노출

## 3. 서비스 이름 후보 (Naming Options)

| 콘셉트 | 추천 이름 | 한줄 슬로건 |
| --- | --- | --- |
| 한국적 + 탐색 | 키워드여지도 | 줌인할수록 선명해지는 대한민국 실시간 핫스팟 |
| 기능 직관성 | 줌인코리아 (Zoom-In Korea) | 지도를 좁히면 단 하나의 트렌드가 보인다. |

| 개발/플랫폼 | ZUMAP (주맵) | 주맵에서 줌해봐! 실시간 동네 키워드 지도 |

## 4. 차별화 포인트 (USP)

- **네이버/카카오맵:** '가게(장소) 핀' 중심이라 일일이 클릭해야 하는 피로감이 있음
  - ➡️ 본 서비스는 **'키워드(텍스트)' 중심**이라 즉각적인 정보 습득이 가능
- **데이터 분석 툴(썸트렌드 등):** 딱딱한 차트와 검색창 중심
  - ➡️ 본 서비스는 지도를 확대/축소하며 탐색하는 **'컨텐츠적 재미(UX)'** 제공

## 5. 개발 메모

- **Frontend:** Mapbox, Leaflet, 혹은 카카오/네이버 지도 API 기반 + Custom Text Overlay(워드클라우드 레이어)
- **Backend/Data:** 일정 주기(예: 1시간)마다 지역별 언급량 수집 → 가중치(TF-IDF 등) 계산 → 줌 레벨에 맞는 데이터 바인딩

기술 설계 상세는 [docs/technical-plan.md](docs/technical-plan.md) 참고.
